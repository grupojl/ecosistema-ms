# Módulo: agents (Agentes IA)

## ¿Qué hace?

Gestiona la configuración de los agentes IA de cada organización:
nombre, personalidad, instrucciones, modelo, etc.

## Estado actual

⚠️ Sin Domain/Repository. Migrar después del MOLDE VIVO (conversations/).

## Funciones principales

- `register` — crear/actualizar configuración de agente
- El agente es una entidad de configuración — su identidad es `agentId` + `organizationId`
